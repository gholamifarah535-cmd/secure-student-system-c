# Secure Student System (C)

Simple student management system with a basic login feature.

## Features
- User login (username & password)
- Add student
- Display students
- Search student
- Delete student

## Description
This project allows managing student data after authentication.  
Data is stored using files in C language.

## Notes
Made for learning file handling, structures and basic system design in C.
